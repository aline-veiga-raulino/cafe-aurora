# ☕ Café Aurora

Landing page desenvolvida como projeto de portfólio para praticar desenvolvimento web com HTML, CSS e JavaScript.

O projeto apresenta a identidade de uma cafeteria inspirada na ideia de café, casa e memória, com foco em uma experiência visual acolhedora e simples.

## ✨ Sobre o projeto

O Café Aurora é uma landing page de uma cafeteria com uma proposta familiar e acolhedora.

A página apresenta:

- Hero com chamada principal
- Cardápio dividido por categorias
- Cafés, doces e salgados
- História da cafeteria
- Informações de contato
- Links para redes sociais
- Menu responsivo para dispositivos móveis

## 📱 Responsividade

O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela.

No desktop, o cardápio utiliza uma estrutura de três colunas. Em telas menores, os produtos são reorganizados em uma única coluna e o menu de navegação passa a utilizar um botão para abrir e fechar os links.
